1. 作業開始（作業指示書の読み取り）▼
ホーム画面の「作業開始」をタップ → 作業指示書を撮影またはファイルを読み取る → 顧客名・ナンバー・車種が自動入力 → 間違いがあれば修正 → 預かりタイヤの有無を自動判定 → 作業予定日を入力してリストに追加

作業指示書がない場合は「手入力で進める」からフォームに直接入力できます。
2. ピット作業▼
カレンダーで日付を選ぶ → その日の作業予定が一覧表示 → カードをタップ → 「履き替え作業を開始する」でタイヤ情報入力画面へ

作業予定日の変更や取り消しもここから行えます。
3. タイヤ情報入力▼
1本目のタイヤを撮影 → Geminiが自動でメーカー・パターン・サイズを読み取り → 結果が全本数にコピー → 各タイヤの残溝を+/-ボタンまたは手入力 → 傷チェック（傷なし/サイドウォール/トレッド面/リム）→ 傷がある場合のみ写真撮影 → 保存で作業完了

残溝3mm未満は赤く「要交換」と表示されます。
4. 倉庫作業（出庫・格納・棚番変更）▼
出庫：出庫準備リストからタイヤを出庫。間違えたら「出庫を取り消す」で戻せます（72時間以内）。

格納：格納待ちリストから棚番号を入力して格納。前回の棚番号がヒントで表示されます。棚番号なしでは格納できません。

棚番変更：検索してタイヤを選び、新しい棚番号を入力。
5. 契約書発行▼
作業完了した車両が一覧表示 → カードをタップ → 顧客・車両・タイヤ情報を確認 → 間違いがあれば編集 → 料金プラン・割引を選択 → 返却予定日を入力 → 「契約書を発行する」
6. 預かり検索▼
顧客名・電話・ナンバー・車種・タイヤサイズ・棚番号・営業担当者で検索。複数条件で絞り込みできます。ひらがなでもカタカナでも検索できます。

「その他の検索条件」を開くとチェック者・顧客コード・メーカー・パターン・作業日・預かり日・返却予定日・申込日・割引区分・メモで検索できます。
7. 返却予定日▼
冬→夏（期日4/20）と夏→冬（期日1/20）の2タブ。3段階で表示：①返却予定日まで14日以内 ②返却予定日を過ぎた ③タイヤホテル期日を超えた
8. トラブル対応▼
ログインできない：ID・パスワードを確認。5回間違えるとロック。管理者に解除依頼。

検索で見つからない：名前2〜3文字で検索。スペース区切りで絞り込み。

出庫を間違えた：倉庫作業の出庫タブで「出庫を取り消す」。72時間以内。

データ入力ミス：顧客台帳・車両台帳から「編集する」で修正。
