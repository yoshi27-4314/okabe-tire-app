1. タイヤホテル スタート（作業指示書の読み取り）▼
ホーム → 「タイヤホテル スタート」ボタン
STEP 1：指示書を読み取る
操作手順
1「カメラで追加」または「ファイルで追加」で作業指示書を撮影
2「この画像で読み取り開始」をタップ
3手書きの場合は「手入力で進める」も可
STEP 2：読み取り結果の確認
操作手順
4顧客情報（氏名・電話等）と車両情報（ナンバー・車種等）を確認・修正
5「確定して次へ」をタップ
STEP 3：預かり判定 → リスト追加
操作手順
6預かりタイヤの有無が自動判定される
7作業予定日を選択して「リストに追加する」
タイヤ返却のみの場合
預かりタイヤがあるお客様で、タイヤを返すだけ（新しい預かりなし）の場合：
1返却予定日を入力
2「タイヤ返却のみ」ボタンをタップ
3確認ダイアログでOK → 出庫準備リストに追加される
返却のみの場合、出庫タブに「返却のみ」と赤字で表示されます。出庫後に「返却完了」ボタンで契約も自動終了できます。
顧客コードで自動照合されます。指示書にコードがあれば、名前が多少違っても既存顧客として認識されます。
2. ピット作業▼
ホーム → 「ピット作業」
操作手順
1カレンダーで作業日を選ぶ（「今日」ボタンで当日に戻れる）
2作業予定のカードをタップして詳細画面へ
3「履き替え作業を開始する」をタップ → 作業中に変更
4「タイヤ情報を入力する」をタップ → タイヤ情報入力画面へ
作業予定日の変更：詳細画面で日付を変えて「作業予定日を変更する」。取り消しも詳細画面から。カード上にはお客様名・ナンバー・車種・出庫状況が表示されます。
3. タイヤ情報入力▼
ピット作業 → 作業中のカード → 「タイヤ情報を入力する」
操作手順
1本数を選択（1〜6本）、預かり区分（夏/冬）を選択
21本目の「カメラ」or「ファイル」でタイヤ側面を撮影 →「読み取り開始」
3メーカー・パターン・サイズ・製造年月が自動入力される（全本にコピー）
4各タイヤの残溝を入力（+1/-1, +0.1/-0.1 ボタン or 直接入力）
5ホイール種別（アルミ/スチール）とキャップ（あり/なし）を選択
6傷チェック：該当する項目にチェック（複数可）
7タイヤの写真を撮影（カメラ or ファイル）
8ナット（お客様保管/車載/共用）を選択
傷チェック項目
小傷 サイドウォール リム ホイールディスク その他
保存ボタンの違い
「一時保存」→ 入力途中でも保存できる。バリデーションなし。後で続きを入力できる。
「保存して作業完了」→ 必須項目（メーカー・サイズ・ホイール・キャップ・写真・預かり区分・ナット）をチェック。全て揃っていれば作業完了になる。
残溝3mm未満は赤く「要交換」と表示されます。写真は傷がなくても撮影必須です。
4. 倉庫作業（出庫・格納・棚番変更）▼
ホーム → 「倉庫作業」（3つのタブで切り替え）
出庫タブ
出庫準備中のタイヤがリスト表示されます。
1対象のカードの「出庫する」ボタンをタップ
2出庫完了。棚番号・本数を確認して倉庫から出す
間違えた場合：「出庫を取り消す」（72時間以内）
返却のみの場合
「返却のみ」と赤字で表示されるカードは、出庫後に「返却完了」ボタン（緑色）が表示されます。お客様にタイヤを渡したら「返却完了」をタップしてください。契約を終了するか確認されます。
格納タブ
作業完了後、預かりタイヤの棚入れを行います。
1格納待ちのカードを確認
2棚番号を入力（前回の棚番号がヒント表示、タップで自動入力）
3「格納」ボタンをタップ
棚番号なしでは格納できません。必ず棚番号を入力してください。
棚番変更タブ
保管中のタイヤの棚番号を変更します。
1顧客名・ナンバー・車種で検索
2対象のカードをタップして選択
3新しい棚番号を入力して「棚番変更を実行」
5. 契約書発行▼
ホーム → 「契約書発行」（2つのタブ）
「発行待ち」タブ — 新規発行
操作手順
1作業完了した車両のカードをタップ
2顧客・車両・タイヤ情報を確認（「編集」リンクで修正可能）
3料金プランを選択（必須）、割引があれば選択
4返却予定日を入力（必須）
5「PDF印刷（契約書3枚）」で印刷してお客様にサイン
6「有効な契約に保管」で契約確定
PDF契約書は3枚構成：お客様控え・契約条項・会社控え。
新しい契約を発行すると、同じ車両の古い契約は自動で終了します。手動で終了する必要はありません。
「有効な契約」タブ — 契約管理
発行済みの契約を一覧で確認できます。カードをタップすると契約詳細画面へ。
連絡状況：返却時期の連絡状況をタグで管理（未連絡・連絡済み・返事待ち・予約入り・連絡不能・督促済）
PDF再印刷：契約詳細からPDF印刷できます（2回目以降は契約番号に枝番が付く）
契約更新：「契約を更新する」で返却予定日を延長
契約終了：「契約を終了する」で契約を終了
6. 預かり検索▼
ホーム → 「預かり検索」
顧客名・電話番号・ナンバー・車種・タイヤサイズ・棚番号・営業担当者・メモで検索できます。複数条件で絞り込み可能。
「その他の検索条件」を開くと、チェック者・顧客コード・メーカー・パターン・作業日・預かり日・返却予定日・申込日・割引区分でも検索できます。
検索結果のカードをタップすると詳細画面が表示され、以下の編集リンクがあります：
・顧客情報を編集 → 顧客台帳へ
・車両情報を編集 → 車両台帳へ
・タイヤ情報を編集 → タイヤ情報入力へ
ひらがなでもカタカナでも検索できます。2〜3文字の短い名前でも検索OK。
7. 返却予定日▼
ホーム → 「返却予定日」（2つのタブ）
冬→夏タブ：冬タイヤ預かり中のお客様（タイヤホテル期日 4/20）
夏→冬タブ：夏タイヤ預かり中のお客様（タイヤホテル期日 1/20）
返却予定日まで14日以内 →「あと○日」表示。そろそろ連絡を。
返却予定日を過ぎた →「予定日超過」表示。連絡が必要です。
タイヤホテル期日を超えた →「期日超過」表示。最優先で対応してください。
8. 割引グループ▼
ホーム → 「設定」→「割引グループ」タブ
顧客コードが違う複数のお客様をグループにまとめて、合算台数で割引を適用できます。例：法人と代表者個人を1つのグループにする。
操作手順
1「新しいグループを作成」でグループ名を入力
2グループをタップして詳細画面を開く
3「顧客を追加」で名前またはコードで検索して追加
自動割引判定
2台以上 → 10%OFF / 3台以上 → 20%OFF / 5台以上 → 30%OFF / 10台以上 → 50%OFF
グループ内の有効な契約台数が自動でカウントされ、割引が判定されます。
9. トラブル対応▼
ログインできない
ID・パスワードを確認。5回間違えるとロックされます。管理者に解除を依頼してください。
読み取りがうまくいかない
指示書が明るい場所で、文字がはっきり見える状態で撮影してください。ぼやけている場合は撮り直してください。「手入力で進める」でも作業できます。
検索で見つからない
名前2〜3文字で検索してみてください。検索条件が多すぎると絞り込みすぎることがあります。
出庫を間違えた
倉庫作業の出庫タブで「出庫を取り消す」をタップ。72時間以内であれば取り消しできます。
タイヤ情報を入力途中で抜けてしまった
「一時保存」をしていれば入力内容は残っています。ピット作業 → 該当のカードから再度入力画面を開いてください。
データ入力ミス
顧客台帳・車両台帳から「編集する」で修正できます。契約書の情報は契約詳細画面で確認してください。
画面が動かない・表示がおかしい
画面右上の「↻」ボタンをタップしてリロードしてください。それでも直らない場合はお問い合わせください。
